## ✨ Qué hace

| | |
|---|---|
| 💱 **Conversión al instante** | Más de 150 monedas con su bandera. Busca por país, nombre o código. |
| 🧮 **Calculadora integrada** | Suma, resta, multiplica, divide y calcula porcentajes (`100 + 10% = 110`), con la conversión en vivo. Toca una cifra para copiarla. |
| 📈 **Evolución** | Gráficos de 1 semana a 5 años, con mínimo, máximo y variación. |
| 🔍 **Varias fuentes** | El tipo de referencia diario junto a otras cotizaciones indicativas, cada una con su hora de consulta. |
| ₿ **Sección Cripto** | Precios de las criptomonedas más conocidas en tu divisa, con variación de 24 h y comparación entre fuentes. |
| 📌 **Siempre visible** | En Windows, la chincheta mantiene la ventana por encima de todo lo demás. |
| 🎨 **A tu estilo** | Tres temas (rosa, día y noche), 6 idiomas y copia de seguridad de favoritos. |
| 🔒 **Privada** | Sin cuentas ni rastreo. Tus datos se quedan en tu equipo. |

## 🪟 Instalar en Windows

1. **[⬇ Descarga `Divisa-and-Go-Setup-1.0.0.exe`](https://github.com/dannymedinacoronel/DivisaGo-support/raw/main/downloads/Divisa-and-Go-Setup-1.0.0.exe)** (99 MB).
2. Ábrelo y sigue el asistente. Puedes elegir la carpeta y crear el acceso directo.
3. ¡Listo! Abre **Divisa&Go** desde el escritorio o el menú Inicio.

> ⚠️ **Windows puede mostrar un aviso.** El instalador aún no tiene firma digital de pago, así que SmartScreen dirá *«Windows protegió su PC»*. Pulsa **Más información → Ejecutar de todas formas**.

### 🔐 Comprueba que es el original

Compara la huella **SHA-256** del archivo descargado con esta:

```
d9cf2656a3cbbd0b3e890c59e7b44fee7adddb8db97d1aa43215592153ca9961
```

En PowerShell: `Get-FileHash .\Divisa-and-Go-Setup-1.0.0.exe -Algorithm SHA256`

## 🧩 Extensión para Chrome

La misma aplicación existe como extensión de Chrome, con tres formas de usarla: **popup**, **ventana flotante** y **panel lateral anclado a la derecha**, cambiando de una a otra sin perder nada.

> 🕒 La extensión está **en revisión** en la Chrome Web Store. En cuanto se publique, el enlace estará aquí.
